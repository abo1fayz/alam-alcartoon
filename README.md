# عالم الكرتون

نسخة ثابتة من منصة **عالم الكرتون**، منشورة عبر GitHub Pages. يعمل الموقع مباشرة من المتصفح ويتصل بـ Supabase باستخدام المفتاح العام فقط.

| المسار | الاستخدام |
|---|---|
| `/` | الموقع العام للمشاهدة والبحث وتصفح المسلسلات |
| `/admin/` | لوحة التحكم المحمية بتسجيل دخول Supabase Auth |

## إضافة حلقة

استخدم رابط YouTube كخيار أساسي، مثل `https://www.youtube.com/watch?v=VIDEO_ID` أو رابط `youtu.be` أو Shorts. تكتشف لوحة التحكم النوع تلقائيًا وتعرضه داخل Plyr. كما يبقى دعم VK Video وكود التضمين الرسمي متاحًا كخيار احتياطي.

تتحقق لوحة التحكم من عدم تكرار **رقم الحلقة داخل الموسم نفسه** قبل رفع الصورة أو الحفظ. إذا كانت الحلقة موجودة، استخدم رقمًا جديدًا أو عدّل الحلقة الحالية.

> لا تضع مفاتيح خدمة Supabase أو ملفات `.env` في هذا المستودع العام.
